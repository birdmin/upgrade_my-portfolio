김경민 (2005년생 / 컴퓨터공학과)

보안전문가로서 성장하는 중인 대학생 김경민의 소개 페이지입니다.

주요 활동 및 역량

1. 웹 보안 취약점 진단

상황: 웹 보안 원리를 익히기 위한 모의해킹 환경 필요

행동: WebHackLab 구축 및 OWASP Top 10 취약점 진단 수행

결과: 주요 취약점 원인 분석 및 대응 방안 정리

• SQL Injection (인증 우회, 데이터 추출)

• Cross-Site Scripting (XSS)

• IDOR (부적절한 인가/접근 제어)

• Command Injection

2. 네트워크 및 CS 역량

상황: 웹 애플리케이션 통신 과정에서의 패킷 및 보안 프로토콜 이해 필요

행동: Chrome DevTools Network 탭을 활용한 HTTP/REST API 패킷 트래픽 추적 및 WebAuthn 통신 디버깅

결과: 클라이언트-서버 간 데이터 흐름 파악 및 HTTP Status Code(401, 200) 분석을 통한 보안 권한 오류 해결 역량 확보

• HTTP/HTTPS 프로토콜 및 REST API 동작 원리 분석

• Chrome DevTools Network 탭을 활용한 트래픽 및 패킷 분석

• WebAuthn / FIDO2 기반 패스키(Passkey) Challenge-Response 인증 프로토콜 구현

• TCP/IP 4계층 및 기본 메모리 구조 이해

3. 디버깅 및 문제 해결

상황: WebHackLab 구축 과정에서 발생한 복잡한 설정 및 코드 에러

행동: 바이브 코딩(AI 활용)으로 원인을 파악하고 서버 로그 추적 후 수정

결과: 시스템 오류의 신속한 해결 및 웹 구성 알고리즘 원리 습득

• AI 프롬프트 기반 코드 에러 원인 즉시 분석

• DB 커넥션 및 웹 서버 설정 디버깅

• 실시간 오류 수정을 통한 문제 해결 역량 확보
